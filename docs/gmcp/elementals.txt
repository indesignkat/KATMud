==============================================================
  Elemental Guild Info : GMCP
==============================================================

GMCP data is sent out of band data sent alongside traditional MUD
output. In order to take advantage of GMCP, your client must support
and some amount of setup is required by the player. See documentation
for your client for more details.

GMCP data is sent as a series of 'packages' formatted as JSON. Warder
guild data is sent in three (3) packages:@ Guild.Info, Guild.State,
and@ Guild.Extra. The data sent with each package is documented below.

Guild.State
The Guild.State package contains the current guild state of the elemental,
including title, size, and skill levels, maximums, and costs.

Guild.Info
The Guild.Info package contains the current guild energy data.

Example full Guild.Info data set
{
    "used_energy": 3072663,
    "energy_to_spend": 9372648,
    "lifetime_energy": 9372648,
    "link_energy": 8044838,
    "reset": "50.2",
}

Guild.Extra
The Guild.State package contains the guild ability data.
